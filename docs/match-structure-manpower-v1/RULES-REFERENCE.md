# Scoped rules reference

Source: [IHF Indoor Handball Rules, 1 July 2025](https://www.ihf.info/sites/default/files/2025-07/09A%20-%20Rules%20of%20the%20Game_Indoor%20Handball_E.pdf), checked 16 October 2026; pages 20–22 and 40.

Rule 8:1 permits passive bent-arm/trunk contact. Rules 8:3–5 distinguish body-directed and dangerous intervention. Rule 16:9 principally applies the strongest punishment for simultaneous/direct-sequence violations before restart, with specific misconduct exceptions.

Implementation inference: the strict stationary, previously committed frontal case should not become an infringement solely because the attacker takes off. Unannounced personal discipline should be resolved together at the stoppage, preserving each physical foul as evidence. The current core has no post-sanction misconduct producer; four-minute misconduct exceptions and the complete IHF discipline system are outside this task.
