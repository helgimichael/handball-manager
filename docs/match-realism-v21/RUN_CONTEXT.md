# Final sample execution context

Final model source was committed locally as `709bfa4` (engine) and `29f62e3` (production bridge) before the final sample. The source byte fingerprints in `after/source-fingerprints.json` identify the exact working source; commit names alone do not replace that evidence. No engine, production observer or benchmark source is edited during the qualified final/controlled/repeat runs.

The final sample uses one sequential Node process, `NODE_OPTIONS=--max-old-space-size=4096`, the original pinned input snapshot and indices 0–99. Cases 0–49 pair with the immutable released v2 AFTER population. Cases 50–99 extend the distribution, and are not silently substituted into a paired comparison. The original six eleven-case calibration stages are preserved separately.

Full core/game verification, production compilation and later actual browser QA overlap some final matches. The full core suite passed 210/210 in 354.03s; those test timings are verification timings, not match simulation timings. Concurrent CPU/memory/browser load can change wall time without changing any seeded match truth. The final report must disclose this overlap rather than claim an isolated speed change.

Per-match `runtimeMs` covers the canonical advancement loop, normal production frame capture and read-only observer. The aggregate `totalRuntimeMs` also includes career construction and per-case evidence export, and is not the sum of simulated game-clock time. Initial script transpilation and initial input/provenance setup precede the aggregate timer. All games still run their actual sixty-minute official clocks.

All thirteen controlled variants completed on indices 0–9, one process at a time, with the exact same source: 130 complete matches. Close-out reused the three independent canonical QA-export simulations already completed for indices 7, 3 and 28. Each matched the sampled initial session, full final core, result, and score/events/RNG/all production frames hashes before export; archived frames round-trip losslessly. The formal proof is `after/repeat-proof.json`. Current source bytes were checked against all 40 qualified fingerprinted files. No completed simulation was repeated during close-out.

The planned extra isolated timing runs of indices 0 and 16 were unnecessary for truth verification and were not run. No isolated before/after speed claim is made. The final hundred-match batch took 1,278.65 seconds including construction/evidence output; actual advancement/frame capture/observer averaged 9.827 seconds per match (median 9.688, p10–p90 7.087–12.398, range 4.498–25.149). The original v2 fifty-match reference averaged 4.317 seconds under different workload/instrumentation. These are recorded engineering timings, not a controlled performance attribution.
