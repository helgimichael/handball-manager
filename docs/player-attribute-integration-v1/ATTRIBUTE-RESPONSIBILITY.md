## Protected boundaries

The strong breakthrough duel remains unchanged. Physical Load v1.1, referee/restart mechanics, substitution rules, ledger ownership, Frikast presentation, career loading and save/archive storage stay unchanged. Defensive technique can use less than the available acceleration; physical capacity still sets its ceiling and fatigue/load remain authoritative. No tactic×attribute bonus, outcome quota, CA/PA shortcut, overall multiplier or match-rating feedback is introduced. Actual database branches are unchanged. The existing synthetic scenario generator now also populates the added schema keys, so construction draw order can differ; paired action probes reset the RNG after construction.

The added stationary cognition eligibility excludes P/P2 carriers, preserving the shared pivot path, and applies only when the existing best shoot/pass values differ by at most0.08; existing eligibility branches remain. Defensive footwork applies only to live court defending jobs and excludes substitution exchanges. The handover delay applies only after shared structure assigns a new responsibility. It does not choose another owner or teleport a defender. A challenged dribble touch creates an actual loose ball; broad loss waits for opponent control.
