37. **HOW TO QA GAME EXPERIENCE.**

    - Open the [visual comparison](comparison.html), switch all five screens and both viewport widths, then start the release with the command above and open its URL.
    - Start a Tumba career. Inspect the matchup, club/league context and roster depth. Open a player and switch tabs; identity should persist. Sort/filter the squad and compare two players.
    - Use Inbox → contract/player and Contracts → renewal. Save/reload. Search and shortlist a target, hire a scout if needed, wait for a real report, compare and approach. Inspect the actual signing and budget/squad consequence.
    - Open another club and competition results/leaders. Review training and calendar. Prepare/play a match, use the same live decisions, inspect the score/report and saved replay, then Save/reload.
    - Reproduce UI QA with `$env:HM_QA_URL='http://localhost:3006'` and `npm run test:e2e:game --workspace=@handball-manager/game`. Run `npm run test:all:portable --workspace=@handball-manager/game` for the full suite. The season proof uses the existing `test:season:management` command, with `HM_SEASON_QA_DIR` optionally set to a separate evidence directory.
