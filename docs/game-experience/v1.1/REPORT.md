43. **HOW TO QA GAME EXPERIENCE v1.1.**

    - Open the comparison viewer; inspect New Game, Tactics, Continue, live controls and the additional rebuilt surfaces at both widths.
    - Create a career, change league/club choices, create a manager and start. Visit saved careers; cancel deletion and load again.
    - Continue, inspect the actual stop and follow its next action. Read an unread item. Filter Squad/Search, open a player and return; controls should remain.
    - Select a handball position and replacement, set tactics, prepare/play. Change tactics, substitute and take an available timeout. Save/reload, finish and inspect report/replay.
    - Review Analysis, Staff, Medical, sporting week and recorded History. Start the next season when complete; prior facts/archives remain.
