- Same initial players, quality, fixtures, seeds and tactics; execution changes consume subsequent RNG along different physical paths, so noise remains.
- No-rotation means zero manager commands; ordinary sanctions can require vacancy replacements. Both experimental AI rotation/timeout policies are disabled equally.
- Energy/acceleration/recovery comparisons are official-time exposure observations, not a fatigue causal estimate for each goal.
- Recovery speed is observed actual motion and recovery acceleration is current physical capacity; duty geometry changes between arms.
- Reception failures are named catch-error events. Canonical no-shot losses remain separately retained in pair files; they are not all technical errors.
- Quarter and half totals derive from the observer segments; raw clock-exclusive helper half splits are not used at the horn boundary.
