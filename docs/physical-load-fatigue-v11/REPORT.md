## 9. previous fatigue architecture

V1 used endurance/squared speed for reserve, optional acute exertion and generic fatigue curves. Execution already read pressure/difficulty. Halftime, bench and timeout windows existed.

## 10. final physical-load architecture

A canonical physicalLoad module now integrates actual locomotion/velocity changes and executed contact/takeoffs. Optional profile fields expose existing HM attributes. No visible UI or Intelligence priorities changed.

## 11. long-term energy

Bounded .15–1 court-player reserve. Sustained work depends on endurance; acceleration/braking/turn/contact/jump cost depends on the corresponding attributes. No minute, score, role or tactic tax.

## 12. acute exertion

Recent work follows actual relative speed, acceleration/deceleration/turn demand and contact/jump impulses. REPEAT_SPRINT_ABILITY changes accumulation; endurance/repeat-sprint capacities govern readiness recovery.

## 13. locomotor load

Squared actual speed integrated over playing time, with existing basal court work. Recorded locomotor totals are independent of player-specific energy efficiency.

## 14. explosive load

Actual velocity gain, loss and lateral redirection have separate small reserve costs. Thousands of small match corrections are not charged like thousands of maximal efforts; early over-depleting pilots are retained in development.

## 15. contact load

Reachable resolved contact loads both bodies once. Sustained close screen engagement loads both for actual contact time. A missed intention/position label creates no contact cost.

## 16. jump load

Only actual takeoff creates jump load, once per jump. Jump ability/explosiveness protect its cost. No invented block jump, jump-height simulator or shot-label jump tax.

## 17. repeat-action load

Recent load compounds actual work and reduces repeat first-step/turn/execution capacity smoothly. The strongest loss is repeated high-intensity work, not one isolated action at 40%.

## 18. player-specific cost

Separate channel resistance: endurance for sustained work; acceleration for first-step work; mobility for braking; agility for direction changes; strength/balance for contact; jump/explosiveness for takeoff.

## 19. player-specific recovery

Readiness recovery uses existing endurance and repeat-sprint attributes, explicitly proxies because no recovery rating exists. Bench/half, timeout and ordinary stopped-clock windows remain distinct.

## 20. position exposure

Physical-load code never reads role. The uniform-physique roles experiment has identical physical capacities across all court positions; observed work still differs.

## 21. wing workload

Wing costs emerge from long running/retreat/transition distances. Actual per-role distributions are in ROLES.json and ROTATION-30.json.

## 22. backcourt workload

Backcourt costs emerge from repeated acceleration, redirection, drives, contact and takeoffs. No V9/H9 multiplier.

## 23. M6 workload
